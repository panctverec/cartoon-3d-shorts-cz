# Reporty vzhledu
Změřená čísla (pohyb kamery, hloubka ostrosti, textury, postavy, světlo, obrysy, barevné ladění) z 20 shorts ve stylu
„2D postavy ve 3D světě“ a recepty, jak je nastavit v enginu. Cesty k výřezům a snímkům uvnitř reportů
(`references/...`) odkazují na soukromý studijní materiál, který v repozitáři záměrně není: platí jen čísla a recepty.
Chceš-li změřit vlastní referenci, postup je v `../vzhled-a-pasti.md` → „Look-match loop“.
