# Ukázkové skripty

Claude podle těchhle skriptů píše styl tvých videí (stavba, tempo, délka vět, humor).

- **Vlastní ukázky:** ulož sem skripty shorts, které se ti líbí, jako `.txt` (jeden skript = jeden soubor).
  Stačí text voiceoveru, ideálně i s odkazem nebo poznámkou, o čem video je. Můžeš je taky vložit Claudovi do chatu,
  uloží je sem sám. Vlastní ukázky mají přednost před výchozími.
- **Výchozí:** `vychozi/` obsahuje ukázkový skript krátkého filmu o mostě (anglicky i česky) a vzorec stylu je
  v `.claude/skills/cartoon-3d-short/reference/vzorec-stylu.md`.

Cizí skripty ber jen jako vzor stavby a tempa. Věty, vtipy a postavy ve tvých videích musí být tvoje.
